# Pagina-Sobre-Mim
  Página web desenvolvida com HTML e CSS, representando a seção "Sobre Mim" do meu portfólio pessoal. Trata-se de uma versão aprimorada do projeto criado durante o 1º período da   graduação, agora com um layout responsivo e melhorias estéticas que tornam a navegação mais agradável e limpa.

# Pontos trabalhados:
  - Layout responsivo
  - Design mais limpo e agradável
  - As divs foram repensadas para modelar apágina melhor.

# Tecnologias Utilizadas:
  - Html
  - Css
